# DEVA 2.0 - Personal AI Voice Assistant

DEVA is an intelligent voice assistant built in Python with PyQt5 GUI and Windows SAPI speech synthesis.

## Features
- Voice commands & natural speech recognition
- Application launching (Notepad, Calculator, VS Code, Chrome, etc.)
- Website opening (direct URLs, domains, and popular web services)
- Real-time weather, news, wikipedia lookups, and math calculations
- Google Calendar integration & Note taking
- System stats monitoring & screenshot capture
